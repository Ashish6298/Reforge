1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Milestone 14.5 establishes the architectural foundation for layered cache trust levels:
  - `trusted local cache` (`TrustMode::TrustedLocal`)
  - `untrusted cache` (`TrustMode::Untrusted`)
  - `read-only cache` (`TrustMode::ReadOnly`)

Under `TrustMode::Untrusted`, the caching engine enforces strict validation guarantees:
  1. Strict Computation Identity Verification:
     Re-derives the canonical SHA-256 key from the embedded `Computation` record on both
     lookup and store operations, immediately rejecting spoofed or tampered key identities.
  2. Multi-Pass CAS Blob Verification:
     Cryptographically checks all referenced output artifacts in the CAS before extraction
     and after staging, quarantining tampered/corrupted blobs before they reach the workspace.
  3. Symlink & Path Traversal Confinement:
     Guarantees that untrusted entries cannot escape the workspace directory or overwrite
     arbitrary host files through symlinks.
  4. Read-Only Protection:
     Guarantees that `TrustMode::ReadOnly` caches disallow any mutations or stores into
     local storage backends.
