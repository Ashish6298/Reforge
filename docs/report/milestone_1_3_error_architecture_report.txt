The error architecture in `crates/cache-core/src/error.rs` models all failure domains:

CacheError
├── StorageError(std::io::Error) ................. Filesystem I/O and CAS storage failures
├── SerializationError(serde_json::Error) ........ Canonical encoding/decoding errors
├── IntegrityError { expected, actual, path } .... SHA-256 digest validation failures
├── CorruptedEntry(PathBuf, String) .............. Malformed or corrupted entry metadata

├── ExecutionError(i32) .......................... Process execution failures (exit != 0)
├── ProcessTerminated ............................ Process aborted by signal
├── KeyGenerationError(String) ................... Invariant validation in key derivation
├── ConfigurationError(String) ................... Misconfigured paths or options
├── ValidationError(String) ...................... Empty fields, invalid arguments
├── PathTraversal(String) ........................ Relative or root path escape attempts
├── MissingOutput(String) ........................ Declared output not created
├── InvalidDigest(String) ........................ Non-hex or invalid length digest
└── Miss(String) ................................. Cache miss fallback
