2. ENVIRONMENT VARIABLE RELEVANCE RULES
--------------------------------------------------------------------------------
- Ambient system variables (e.g. USER, TMP, PATH, process IDs) are NOT automatically
  hashed into the computation identity to prevent unnecessary cache fragmentation.
- Only explicitly declared environment variables needed for computation correctness
  are recorded into the computation identity.
- Environment variables are lexicographically ordered in a BTreeMap to guarantee
  deterministic canonical JSON key generation.
