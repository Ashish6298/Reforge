1. SCOPE BOUNDARIES & NON-GOALS AUDIT
--------------------------------------------------------------------------------
The v1 architecture explicitly limits scope and verifies that DCC is NOT:
1. A remote build farm (no distributed worker orchestrator in v1)
2. A distributed execution engine (local-first process execution)
3. A Docker replacement (no container runtime or kernel cgroups)
4. A package manager (no registry resolution, downloads, or locking)
5. A full Bazel replacement (no multi-language build DAG DSL)
6. A compiler (wraps existing compilers, does not parse ASTs)
7. A CI platform (runs inside existing CI runners like GitHub Actions)
8. A cloud service (100% offline and local-first)
9. A build system (wraps discrete build steps, does not orchestrate DAGs)
