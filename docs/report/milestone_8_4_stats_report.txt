1. OBJECTIVE & SCOPE
--------------------------------------------------------------------------------
Milestone 8.4 requires implementing and verifying the comprehensive cache statistics
inspection capability in DCC (`dcc stats`), reporting:
  - entries (total cache entry records)
  - objects (total physical CAS objects)
  - disk usage (objects, entries, and total disk usage)
  - hits (total hit count aggregated across all entries)
  - misses (total initial executions/misses)
  - hit ratio (aggregate hit percentage)
  - bytes restored (cumulative bytes saved and restored on hits)
  - bytes stored (total bytes produced and stored)
  - estimated time saved (cumulative execution duration avoided by cache hits)
  - largest object size in bytes

2. ARCHITECTURE & IMPLEMENTATION
--------------------------------------------------------------------------------
1. StorageStats Collection Engine (`crates/cache-storage/src/stats.rs`):
   - Scans entries in `entries/` directory and parses `CacheEntry` metadata:
     * `total_entries`: Count of valid JSON entries.
     * `total_entry_size_bytes`: Aggregate filesystem bytes of entry JSON files.
     * `total_hits`: Sum of `entry.metadata.hit_count`.
     * `total_misses`: Count of recorded entries (each stored entry represents an initial miss).
     * `bytes_stored`: Sum of `entry.outputs[..].size`.
     * `bytes_restored`: Sum of `(entry.outputs[..].size * entry.metadata.hit_count)`.
     * `estimated_time_saved_ms`: Sum of `(entry.metadata.execution.execution_time_ms * entry.metadata.hit_count)`.
     * `hit_ratio`: `total_hits as f64 / (total_hits + total_misses) as f64`.
   - Scans objects in `objects/` directory:
     * `total_objects`: Count of physical blob files.
     * `total_object_size_bytes`: Aggregate size of all CAS blobs.
     * `largest_object_size_bytes`: Maximum single blob size.
     * `largest_object_path`: Path to largest object.

2. CLI Command Handler (`crates/cache-cli/src/main.rs`):
   - `handle_stats(&storage, json)` formats statistics cleanly:
     * Human-readable text format with aligned columns and unit conversions (MB, KB, seconds).
     * Structured JSON format with `--json` flag.
