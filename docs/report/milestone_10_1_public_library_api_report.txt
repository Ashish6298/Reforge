1. OVERVIEW
--------------------------------------------------------------------------------
Milestone 10.1 designs and delivers a clean, idiomatic, high-level Rust library API
allowing external tools, build systems, code generators, and linters to embed DCC
directly without relying on subprocess invocations of the CLI.

The API cleanly abstracts and hides internal Content-Addressable Storage (CAS)
mechanics (such as 2-level directory sharding, temporary file promotion, advisory file
locking, TTL eviction, and integrity quarantine).

2. KEY ARCHITECTURAL & API ADDITIONS
--------------------------------------------------------------------------------
1. `Cache::open(path)` & `Cache::open_with_config(config)`
   - Defined on `dcc_storage::Cache` and re-exported via `dcc_integrations::Cache`.
   - Opens or initializes a DCC storage workspace with default or customized storage configurations.

2. `ComputationBuilder::new(...)`
   - Fluent builder in `dcc_core::ComputationBuilder` for constructing `ComputationSpec`.
   - Supports:
     * `ComputationBuilder::new(identifier)`
     * `ComputationBuilder::operation(op)`
     * `ComputationBuilder::command(cmd)`
     * `with_arguments(...)`
     * `with_inputs(...)`
     * `with_outputs(...)`
     * `with_env(...)`
     * `with_tool(...)`
     * `with_platform(...)`
     * `build()`

3. Storage Operations on `Cache`:
   - `cache.lookup(&key)` -> `Result<Option<CacheEntry>>`
   - `cache.store(&key, &entry, &blobs)` -> `Result<()>`
   - `cache.restore(&entry, &output_dir)` -> `Result<()>`
   - `cache.contains(&key)` -> `Result<bool>`
   - `cache.verify(&key)` -> `Result<bool>`
   - `cache.remove(&key)` -> `Result<bool>`
   - `cache.stats()` -> `Result<StorageStats>`
   - `cache.collect_garbage(...)` -> `Result<GarbageCollectionReport>`

4. Execution API:
   - `RunnerEngine::from_cache(cache, options)` in `dcc_runner`
   - `GenericIntegration::from_cache(cache, options)` in `dcc_integrations`
   - `integration.execute(&spec, &work_dir)` -> `Result<ExecutionResult>`
   - Re-exports entire public surface via `dcc_integrations`:
     * `dcc_integrations::Cache`
     * `dcc_integrations::ComputationBuilder`
     * `dcc_integrations::GenericIntegration`
     * `dcc_integrations::dcc_core`
     * `dcc_integrations::dcc_runner`
     * `dcc_integrations::dcc_storage`
