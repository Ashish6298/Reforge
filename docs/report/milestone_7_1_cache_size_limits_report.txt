1. EXECUTIVE SUMMARY & OBJECTIVE
--------------------------------------------------------------------------------
Milestone 7 addresses the lifecycle management and bounded growth of the Developer
Computation Cache (DCC). Milestone 7.1 specifically establishes flexible, robust,
and human-friendly Cache Size Limit configurations (`max_size`).

A production-quality developer cache must never grow unbounded until it exhausts host
disk space. It must support ergonomic, human-readable size limits such as:
  - 500 MB
  - 2 GB
  - 10 GB
  - Custom byte specifications and fractional units (e.g. 1.5 GB, 512 KiB)

--------------------------------------------------------------------------------
2. ARCHITECTURAL DESIGN & IMPLEMENTATION
--------------------------------------------------------------------------------

1. Human-Readable Size Parsing Engine (`crates/cache-core/src/size.rs`):
   - Introduced the `ByteSize` type representing byte quantities with robust parsing,
     formatting, and serde capabilities.
   - Supports standard binary and decimal suffixes:
     * Bytes: `B`, `bytes`, `byte`, raw integers (e.g., `1048576`)
     * Kilobytes: `KB`, `KiB`, `kbytes`, `k` (1024 B)
     * Megabytes: `MB`, `MiB`, `mbytes`, `m` (1024^2 B)
     * Gigabytes: `GB`, `GiB`, `gbytes`, `g` (1024^3 B)
     * Terabytes: `TB`, `TiB`, `tbytes`, `t` (1024^4 B)
   - Supports flexible whitespace, case-insensitivity, and fractional values (e.g. `1.5 GB`, `0.5 MB`).
   - Implements `Display`, `FromStr`, `From<u64>`, `From<ByteSize> for u64`, and custom
     `Serialize`/`Deserialize` to seamlessly handle both numeric JSON and string configuration formats.

2. Storage Configuration Integration (`crates/cache-storage/src/cas.rs`):
   - Enhanced `StorageConfig` with builder and accessor helpers:
     * `StorageConfig::new(root_dir)`
     * `with_max_size(impl Into<ByteSize>)`
     * `with_max_size_str(&str) -> Result<Self, SizeParseError>`
     * `max_size(&self) -> Option<ByteSize>`
   - Default cache size limit is set to 10 GB (`10 * 1024 * 1024 * 1024` bytes).
   - Exposed `CasStorage::config(&self)` and `CasStorage::max_size(&self)`.

3. CLI Integration (`crates/cache-cli/src/cli.rs` & `crates/cache-cli/src/main.rs`):
   - `dcc init --max-size <SIZE>`: Accepts human-readable strings (e.g. `--max-size "2 GB"` or `--max-size 500MB`).
   - `dcc prune --max-size <SIZE>`: Enables manual or automated LRU eviction down to the specified size.
   - Formatted diagnostic and JSON output includes both raw bytes and formatted human-readable representations.
