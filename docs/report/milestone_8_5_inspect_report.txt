2. ARCHITECTURE & IMPLEMENTATION
--------------------------------------------------------------------------------
1. CLI Handler (`crates/cache-cli/src/main.rs`):
   - `handle_inspect(&storage, key_str, json)` parses `<key>`, looks up the `CacheEntry` in CAS:
     * `key`: Canonical SHA-256 computation digest string.
     * `operation`: Logical operation identifier.
     * `command`: Target executable or command.
     * `arguments`: Formatted argument vector.
     * `inputs`: Formatted list of all declared input files with sizes and SHA-256 hashes.
     * `outputs`: Formatted list of all generated output files with sizes and CAS blob hashes.
     * `tool identity`: Name, version, and binary executable hash (or "none").
     * `environment`: Count and list of all explicitly declared environment variables.
     * `created`: `entry.metadata.created_at` timestamp.
     * `last accessed`: `entry.metadata.last_accessed_at` timestamp.
     * `size`: Total byte size and human-readable KB/MB output size.
     * `integrity`: Validates canonical key identity using `entry.verify_identity()`
       (reporting "Valid (matches canonical computation key)" or integrity error).

2. Dual-Format Support:
   - Text Mode: Aligned and formatted summary.
   - JSON Mode (`--json`): Structured full JSON serialization of `CacheEntry`.
