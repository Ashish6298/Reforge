1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Milestone 15.4 produces the comprehensive Remote Cache Architecture & Protocol
Specification document at `docs/remote-cache.md`.

Key areas fully defined in the design document:
  1. Protocol Possibilities:
     - REST over HTTP/1.1 & HTTP/2 with CDN / reverse proxy compatibility.
     - gRPC (Bazel REAPI compatible) for bi-directional batching & streaming.
     - S3 / Blob Storage object protocol for direct cloud storage integration.
  2. Authentication & Authorization:
     - Bearer Tokens, API keys, and mutual TLS (mTLS).
     - Role-Based Access Control (RBAC): `ReadOnly`, `ReadWrite`, `Admin`.
     - Short-lived pre-signed URLs for cloud direct blob uploads.
  3. Integrity & Anti-Poisoning:
     - Streaming cryptographic SHA-256 validation on downloads.
     - Canonical key recalculation on Action Cache entry payloads.
     - Workspace boundary containment and symlink attack prevention.
  4. Upload & Download Flows:
     - Sequence diagrams for missing blob discovery, upload, and atomic download.
  5. Cache Namespaces & Multi-Tenancy:
     - Namespace isolation for Action Cache metadata.
     - Global deduplication across namespaces for immutable CAS blobs.
  6. Versioning & Compatibility:
     - Metadata schema versioning (`schema_version: u32`).
     - Protocol version headers and capability negotiation.
  7. Secret Protection:
     - Integration with `SensitiveDataPolicy` (`Deny` / `Warn` / `Mask`).
     - Transport-layer TLS 1.3 and at-rest envelope encryption.
  8. Failure Behavior & Graceful Degradation:
     - Strict guarantee: Remote cache failures never break builds; transparent
       fallback to local execution on network timeouts, 5xx server errors, or 403 errors.
