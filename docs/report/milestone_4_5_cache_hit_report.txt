1. OBJECTIVE & REQUIREMENTS
--------------------------------------------------------------------------------
The objective of Milestone 4.5 is to implement and enforce the exact 6-step
Cache Hit lifecycle guarantees:

On a cache hit:
1. Retrieve metadata (`get_entry(&key)`)
2. Verify cache integrity (`verify_identity()` & CAS blob SHA-256 validation)
3. Restore outputs (`OutputRestorer::restore_entry` with atomic rename & permissions)
4. Restore metadata if requested (replays stdout, stderr, exit code, execution telemetry)
5. Report HIT (`ExecutionStatus::Hit`, miss_reason: None)
6. Do not execute the command (complete bypass of child OS process execution)

2. IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------
- Step 1: Retrieve Metadata
  * RunnerEngine queries Content-Addressed Storage via `storage.get_entry(&key)`.
  * Automatically deserializes `CacheEntry` JSON manifest and increments access
    counters (`hit_count`, `last_accessed_at`).

- Step 2: Verify Cache Integrity
  * `entry.verify_identity()` recalculates the canonical `CacheKey` from the
    embedded `Computation` and compares it against `entry.key`.
  * `OutputRestorer::restore_entry` verifies every referenced CAS blob digest
    before streaming.
  * If any corrupted metadata or CAS blob is encountered, the invalid entry is
    quarantined/removed and the engine falls back safely to execution with
    `MissReason::CorruptedCache`.

- Step 3: Restore Outputs
  * Reconstructs required parent directory hierarchies safely.
  * Streams verified output blobs to temporary files alongside destinations.
  * Verifies checksum of the restored file on disk against expected SHA-256.
  * Atomically moves (`rename`) files into their final declared workspace paths.
  * Restores Unix executable bits if declared.

- Step 4: Restore Metadata
  * Reconstitutes captured stdout and stderr buffers from CAS reader.
  * Preserves recorded exit code and returns `execution_time_ms = 0`.

- Step 5: Report HIT
  * Emits structured hit event.
  * Returns `ExecutionResult` with `status: ExecutionStatus::Hit`, `miss_reason: None`.

- Step 6: Process Execution Bypass
  * The child OS process (`ProcessExecutor::execute`) is NEVER invoked.
  * Eliminates CPU, I/O, and build tool overhead completely.
