3. ARCHITECTURAL GUARDS & IMPLEMENTATION DETAILS
--------------------------------------------------------------------------------

- In RunnerEngine::execute:
  Cache lookup cleanly matches on Result<Option<CacheEntry>, CacheError>.
  If a metadata entry is corrupted on disk (e.g. invalid JSON, truncated file, or
  tampered computation identity), RunnerEngine:
    1. Catches the error and logs corruption telemetry.
    2. Quarantines/deletes the corrupted entry file.
    3. Triggers run_and_store with MissReason::CorruptedCache { reason }.
    4. Safely executes the computation, restores output manifests, and heals the
       cache entry record with fresh, verified state.

- In CasStorage & OutputRestorer:
  Every CAS blob retrieval verifies SHA-256 checksums before touching the workspace.
  If a CAS object on disk differs from its digest name, it is immediately renamed
  to <digest>.corrupted, preventing poisonous cache hits.
