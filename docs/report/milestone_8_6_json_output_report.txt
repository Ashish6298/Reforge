1. OBJECTIVE & SCOPE
--------------------------------------------------------------------------------
Milestone 8.6 requires implementing and verifying machine-readable structured JSON
output across all major CLI commands via the global `--json` flag:
  - `dcc stats --json`
  - `dcc inspect <key> --json`
  - `dcc run --json`
  - `dcc init --json`
  - `dcc doctor --json`
  - `dcc verify --json`
  - `dcc config --json`
  - `dcc prune --json`
  - `dcc clean --json`

2. ARCHITECTURE & IMPLEMENTATION
--------------------------------------------------------------------------------
1. Global CLI Parser Flag (`crates/cache-cli/src/cli.rs`):
   - Defined `#[arg(long, global = true, help = "Output result in JSON format")] pub json: bool`
     on `Cli` struct so that `--json` is parsed universally across all subcommands.

2. Command Handler JSON Encodings (`crates/cache-cli/src/main.rs`):
   - `handle_run`: Serializes `ExecutionResult` including status (`hit`/`miss`/`bypassed`),
     canonical `key`, `exit_code`, `execution_time_ms`, `miss_reason`, `stdout`, `stderr`,
     and `restored_outputs`.
   - `handle_inspect`: Serializes full `CacheEntry` JSON schema with computation spec,
     inputs, outputs, execution metrics, timestamps, and integrity info.
   - `handle_stats`: Serializes `StorageStats` with total entries, total objects, object bytes,
     entry bytes, total size, largest object, hits, misses, hit ratio, bytes stored/restored,
     and estimated time saved.
   - `handle_init`: Serializes initialization report with directory paths and max size settings.
   - `handle_doctor`: Serializes diagnostic health, storage accessibility, and object counts.
   - `handle_verify`: Serializes `{ "verified_objects": n, "corrupted_objects": m, "status": "healthy"|"corruption_detected" }`.
   - `handle_config`: Serializes key/value pairs or complete configuration layout.
   - `handle_prune`: Serializes `EvictionResult` with deleted entries, deleted objects, and freed bytes.
   - `handle_clean`: Serializes clean confirmation with status or specific deleted key.
