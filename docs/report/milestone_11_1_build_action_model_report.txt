1. OBJECTIVE & REQUIREMENTS
--------------------------------------------------------------------------------
Milestone 11.1 establishes the action-oriented build caching model:
- Represent a build action encapsulating:
  * compiler (compiler executable, e.g. rustc, gcc, clang)
  * arguments (compiler options, flags, optimization levels)
  * source inputs (primary source files with content digests)
  * dependency inputs (compiled libraries, headers, rlibs)
  * compiler version (explicit tool identity and version string)
  * target (target triple / platform constraints)
  * environment (declared compiler environment variables)
  * outputs (expected output binaries, libraries, manifests)
- Map `BuildAction` to canonical `Computation` for deterministic hashing and execution.
- Maintain pre-execution validation and canonical path normalization.
- Ensure integration into `dcc-integrations` without breaking existing UI or CLI functionality.
