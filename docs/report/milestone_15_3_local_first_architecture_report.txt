1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Milestone 15.3 designs and implements the conceptual multi-tier cache hierarchy:
  - `L1: Memory`: Ultra-fast in-process RAM cache (`RemoteStorage` / in-memory table).
  - `L2: Local Disk`: Primary content-addressable filesystem storage (`LocalCasStorage`).
  - `L3: Remote Cache`: Optional distributed/cloud remote storage tier (`Arc<dyn Storage>`).

Key local-first architectural guarantees implemented:
  1. Local-First Operation:
     In v1, operation requires only local disk (`L2`) and memory (`L1`). The engine
     operates 100% locally and offline by default without requiring external servers.
  2. Hierarchy Traversal & Automatic Promotion:
     - On lookups: Queries L1 Memory -> L2 Local Disk -> L3 Remote Cache in order.
     - On cache hit in L2: Blob is promoted to L1 Memory for subsequent fast queries.
     - On cache hit in L3: Blob is promoted to both L2 Local Disk and L1 Memory.
  3. Write Propagation:
     Stores write immediately to L1 Memory and L2 Local Disk, and opportunistically
     synchronize with L3 Remote Cache if configured.
  4. Explicit Tier Discovery (`TieredCache::locate_tier`):
     Enables callers and diagnostic tools to inspect which physical tier (`CacheTier::L1Memory`,
     `CacheTier::L2LocalDisk`, `CacheTier::L3RemoteCache`) is currently serving a blob.
