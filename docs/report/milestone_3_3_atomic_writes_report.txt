1. OBJECTIVE & REQUIREMENTS:
--------------------------------------------------------------------------------
- Never write cache objects or metadata entries directly into their final location.
- Implement the strict two-stage atomic write pipeline:
    temporary file (tmp/)
          ↓
        write
          ↓
        flush
          ↓
    sync (fsync / sync_all)
          ↓
        rename
- Ensure the system never leaves a partially-written, incomplete, or corrupted
  cache object in the live content-addressed storage.
- Guarantee that interrupted or concurrent writes do not leave dangling temporary
  files or corrupt valid existing entries.

2. IMPLEMENTATION DETAILS:
--------------------------------------------------------------------------------
- CAS Object Storage (`CasStorage::store_object_bytes` & `store_object_from_file`):
    * Generates unique temporary filenames in `tmp/` using PID, timestamp, and atomic counter.
    * Opens `.tmp` file with `create_new(true)`.
    * Streams or writes data into `BufWriter`.
    * Calls `dst.flush()?` to flush userspace buffers.
    * Calls `dst.get_ref().sync_all()?` (`fsync`) ensuring physical disk persistence before renaming.
    * Atomically renames temporary file to `objects/{prefix}/{digest}`.
    * Cleans up temporary file if any step fails.
- Entry Metadata Storage (`CasStorage::store_entry`):
    * Serializes JSON to temporary file in `tmp/`.
    * Flushes and syncs (`sync_all`) before atomic rename to `entries/{prefix}/{key}.json`.
- Output Restoration (`OutputRestorer::restore_entry` & `Cache::restore`):
    * Restores blobs via `.tmp_restore_{digest}` staging files.
    * Verifies content digest on disk before renaming to final target artifact path.
