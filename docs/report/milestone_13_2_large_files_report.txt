3. MEMORY USAGE & STREAMING ANALYSIS
--------------------------------------------------------------------------------
- Streaming Architecture:
  * Hashing: `Digest::hash_reader` operates on streaming `Read` sources with a 64 KB
    stack buffer, computing cryptographic digests incrementally without heap buffering.
  * CAS Ingestion: `CasStorage::store_object_from_file` streams bytes via `std::io::copy`
    and `BufWriter` directly into temporary staging files in `.dcc_cache/tmp/`.
  * Atomic Restoration: `OutputRestorer::restore_entry` / `Cache::restore` streams
    CAS blobs chunk-by-chunk directly to destination paths with streaming checksum
    verification before atomic replacement.
- Constant Heap Footprint:
  * Total resident memory remains flat and constant regardless of whether processing
    1 MB or 1 GB files.
