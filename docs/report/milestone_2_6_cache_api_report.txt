1. OBJECTIVE & SCOPE:
--------------------------------------------------------------------------------
- Design and implement a clean, decoupled, library-level Cache API.
- Ensure CLI commands, build tool integrations, and computation runners consume
  the library API rather than implementing ad-hoc cache logic.
- Support core primitives:
    * cache.lookup(key) -> Result<Option<CacheEntry>>
    * cache.store(entry) -> Result<()>
    * cache.restore(entry, destination_dir) -> Result<()>
    * cache.remove(key) -> Result<bool>
    * cache.contains(key) -> bool
    * cache.verify(key) -> Result<()>
- Ensure output blobs remain decoupled from metadata records, with atomic
  restoration, directory traversal protection, and verification against corrupted CAS data.

2. IMPLEMENTED ARCHITECTURE & TYPES:
--------------------------------------------------------------------------------
- `dcc_storage::Cache` struct (`crates/cache-storage/src/cache.rs`):
    * `lookup(&self, key: &CacheKey) -> Result<Option<CacheEntry>>`
      Fetches cache entry and updates LRU metadata (last_accessed_at, hit_count).
    * `store(&self, entry: &CacheEntry) -> Result<()>`
      Atomically serializes and saves entry JSON via temporary files.
    * `restore(&self, entry: &CacheEntry, destination_dir: &Path) -> Result<()>`
      Verifies CAS blobs, streams content safely to temporary staging files,
      performs post-restore cryptographic checksum validation, and atomically places
      artifacts at their destination paths while preventing directory traversal.
    * `remove(&self, key: &CacheKey) -> Result<bool>`
      Removes a cached entry by its key.
    * `contains(&self, key: &CacheKey) -> bool`
      Fast O(1) file existence check for a cache key.
    * `verify(&self, key: &CacheKey) -> Result<()>`
      Full integrity audit: verifies that the metadata entry exists and parses,
      and validates cryptographic hashes for all referenced output, stdout,
      and stderr blobs in the CAS storage.
    * Auxiliary methods: `store_bytes()`, `store_file()`, `contains_blob()`,
      `verify_blob()`, `lock()`, `stats()`, `pruner()`.
