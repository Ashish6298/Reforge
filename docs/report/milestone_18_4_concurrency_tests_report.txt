1. OBJECTIVE & SPECIFICATION
--------------------------------------------------------------------------------
Milestone 18.4 mandates exhaustive verification of the system under high-concurrency
and multithreaded stress across 6 critical operational scenarios:

1. Many Readers:
   Multiple reader threads concurrently accessing, streaming, and verifying
   the same CAS objects and metadata records simultaneously with zero lock contention
   or torn reads.

2. Many Writers:
   Multiple writer threads simultaneously committing distinct objects and racing
   on identical payloads to verify lock-free atomic deduplication and temp directory
   hygiene.

3. Same-Key Writers:
   Multiple concurrent runners computing and storing the exact same computation key
   simultaneously. Verifies advisory `ComputationLock` synchronization and secondary
   cache re-check so that the expensive computation executes exactly once (1 Miss)
   while remaining threads wait and receive 0 ms cache Hits.

4. Different-Key Writers:
   Multiple concurrent runners computing independent keys concurrently, verifying
   parallel execution without mutual blocking or deadlock.

5. Reader + Writer:
   Simultaneous execution of active reader threads streaming existing objects and
   metadata while active writer threads insert new entries and CAS objects.

6. Pruner + Reader:
   Active reader threads holding shared `ObjectLock` read handles while garbage
   collection (`Pruner`) runs, verifying that objects currently in active use are
   safely preserved and never deleted mid-stream.
