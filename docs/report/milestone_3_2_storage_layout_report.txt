1. OBJECTIVE & REQUIREMENTS:
--------------------------------------------------------------------------------
- Implement and enforce the content-addressed directory structure for DCC:
    .cache/
    ├── objects/
    │   ├── ab/
    │   │   └── cdef...
    │   ├── 12/
    │   │   └── 98af...
    ├── entries/
    │   ├── 01/
    │   └── 9f/
    ├── metadata/
    ├── index/
    ├── tmp/
    └── locks/
- Prevent performance degradation from having millions of files in a single directory.
- Distribute both CAS objects and computation metadata entries across 2-character hex
  prefix buckets (`digest.prefix(2)` / 256 subdirectories).
