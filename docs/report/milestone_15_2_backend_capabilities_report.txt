1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
Milestone 15.2 defines and implements explicit backend capabilities and batch operation
primitives on the `Storage` abstraction trait:

Key capabilities implemented:
  1. Fine-Grained Capability Descriptor (`StorageCapabilities`):
     - `read`: Query and retrieve stored blob payloads.
     - `write`: Persist bytes into content-addressed storage.
     - `delete`: Remove objects and free space.
     - `exists`: O(1) membership test for blobs.
     - `stream`: Stream file contents directly to/from disk without buffering entire objects.
     - `batch_get`: Parallel/bulk retrieval of multiple digests in a single invocation.
     - `batch_put`: Parallel/bulk persistence of multiple payloads in a single invocation.

  2. Storage Capability Invariants:
     - `StorageCapabilities::all()`: Standard full read-write storage backends (`LocalCasStorage`, `RemoteStorage`).
     - `StorageCapabilities::read_only()`: Read-only mirrors and untrusted replicas.
     - `StorageCapabilities::basic()`: Stream-oriented backends without batch optimizations.

  3. Batch Acceleration Primitives:
     - `batch_get(&[Digest]) -> Result<Vec<(Digest, Option<Vec<u8>>)>>`:
       Retrieves multiple blobs efficiently, returning `None` for missing digests rather than
       failing the entire batch.
     - `batch_put(&[&[u8]]) -> Result<Vec<(Digest, u64)>>`:
       Computes hashes and stores multiple blobs in one batch operation.
